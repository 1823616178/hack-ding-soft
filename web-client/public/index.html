APK API CLIENT

eFaceGo 接口薄客户端

调用原 APK 的服务端接口，不重写考勤、围栏或人脸业务逻辑。

1

服务器与账号

只填写协议、主机和可选端口；实际请求路径由客户端按 APK 拼接。

2

打卡时间与地点

默认保持原 APK 时间语义；自定义模式会同时覆盖 checkLocation 和 addCard 的时间。

3

人脸 JPEG 照片

按原字段 photo 上传。这里只对接接口，不执行 APK 的 native 人脸比对或活体判定。
